This code was used to perform analyses using reported in the following Stage 2 Registered Report:
Jia, Z., Ozaki, Y., Pavlovich, D. V., Huang, J., Benetos, E., Khasanah, U., Calhoun, S., Chiba, G., Kitayama, Y., Fujii, S., Sadaphal, D. P., Fitch, W. T., Vaida, S., Echim, S., Popescu, T., Shi, Z., Grassi, M., Guiotto Nai Fovino, L., Hajič jr., J., Nuska, P., …, Savage, P. E. (In Principle Accepted). Synchronised group singing enhances social bonding more than group conversation or recitation does: A Registered Report across 30 languages. Peer Community In Registered Reports. Preprint: https://doi.org/10.31234/osf.io/pv3m9_v6

To replicate the analyses, clone this repository (e.g., using GitHub Desktop) and the "00_run_all.R" script from the "stage2(full)" directory using R (or R Studio). Most of the scripts should run rapidly (less than a few minutes) using only the R programming language, except for the Bayesian analyses (subscripts "04_confirmatory_analysis_01.R" and "05_confirmatory_analysis_02.R"), which can take a few hours and require Stan. 
Note that the pre-processing script ("01_preprocessing.R") is provided for transparency, but has been commented out because it requires files that cannot be shared publicly. This script creates files containing publicly shareable participant data ("stage2data.csv") and experimenter log ("experimentlog.csv"), which are available in the 'data/raw/' directory along with the "CollaboratorsPlotData.csv" file containing geographic coordinates and metadata of the 43 experimen sites. These three raw data files are the basis for all further analysis scripts, which then save processed data, figures, tables, etc. in associated "data/processed" and "outputs" directories. 

Some minor changes in the analysis pipeline were introduced in the course of peer review of the Stage 1 protocol. To replicate the pilot analyses from the original Stage 1 Registered Report protocol, run the "SongSpeechCooperation(Pilot).R" script from the "stage1(pilot)" directory.
